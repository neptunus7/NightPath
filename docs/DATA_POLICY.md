## 이 문서의 결론

1. **공공누리 제1유형**은 출처 표시 조건 아래 상업·비상업 이용과 변형이 가능하다고 안내하지만, 별도의 측량성과 **국외 반출 법규** 판단을 대신하지 않습니다.
2. 한국 「공간정보의 구축 및 관리 등에 관한 법률」 제16조(기본측량성과), 제21조(공공측량성과)는 국외 반출 제한을 규정하고 있습니다. **어떤 파일/가공 형태/해외 클라우드가 심사 대상인지 구체적인 허가 주체의 답변을 기다리는 중**이며, 승인 전 NGII 원본·파생 좌표는 공개 저장소에 올리지 않습니다.
3. GitHub **Private**와 공개 저장소는 열람 권한이 다르지만, **해외 저장소 업로드 자체**의 허용 여부를 별도로 판단해야 합니다. 비공개라서 무조건 법적 허용이라고 보지 않습니다.
4. 공개용 코드 폴더에 실제 데이터가 없다는 것은, 자체 코드를 오픈소스로 공개할 수 있다는 뜻이지 **프로젝트에 사용한 모든 제3자 데이터/지도 화면을 자유롭게 공유할 수 있다는 뜻이 아닙니다.**
5. 향후 기관 회신이나 면허 재검토로 허용 범위가 명확해지면 **별도의 데이터 배포 결정**을 진행합니다. 이 ZIP을 임의로 바꿔 원본 지도를 포함시키면 검증 결과는 무효입니다.
