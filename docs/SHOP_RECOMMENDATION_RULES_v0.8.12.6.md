# 편의점 추천 규칙 — v0.8.12.6

1. OSM에 `shop=convenience`가 있는 편의점과 위치 좌표를 추출합니다.
2. 현재 필터로 구축한 보행 후보망에 **최대 150m** 거리로 스냅될 수 있어야 합니다.
3. 출발점과 해당 스냅 노드 사이 최단 보행거리 **1,450m 이하**인 후보를 대상으로 합니다.
4. 기존 점수 계산은 `0.75 × 조명근접 구간비율 + 0.25 × 조명근접도 - 0.12 × (추천 이동거리 / 최대보행거리)`이며, 개별 경로는 최단 대비 최대 35% 우회해 조명 근접도를 개선할 수 있습니다.
5. 목록은 **가장 가까운 두 후보 + 나머지 기존 점수 상위**로 최대 8곳을 표시합니다. 가까운 두 후보는 '가까운 곳'이라고 구분합니다.

주의: OSM에는 등록되지 않은 편의점이나 연결 그래프에 접근할 수 없는 편의점은 빠질 수 있습니다. 직선거리와 모델상의 최단거리도 다릅니다. 24시간 영업 가정은 **화면의 파란빛 시연**에만 쓰며 영업/실제 빛 여부나 경로 점수에는 쓰지 않습니다.
