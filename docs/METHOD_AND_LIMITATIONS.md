# 추천 모델: 구현·검증·한계

## 데이터 분류

- **NGII 2025:** 지상 조명시설 관련 위치 기록. `C0220000` 레이어에서 추출한 가로등/보안등 기록. 좌표·도엽 범위는 이 저장소에 배포하지 않습니다.
- **2026 IoT:** 측정 장치의 기록 좌표. 0/100 등 관측 필드는 실측 lux로 취급하지 않습니다.
- **OSM:** 도로/보행망·일부 편의점 위치. 지도 데이터 ODbL 및 타일 이용정책은 별개입니다.
- **2022 안심 인프라:** 과거 지정 구간과 시설 위치 기록. 현재 시설 존재·운영·안전성 미확인.

## 계산 원칙

- 최광루트는 `lightRadius`로 시설 종류/일반야간·심야에 따라 가정한 거리 근접도를 평가합니다. 일반 예: 가로등 15m/보안등 8m; 심야 보수 예: 11m/6m. **광학 기반 실제 조도 확산 범위가 아닙니다.**
- 안심 참고형은 **2022년 기록과의 근접도**를 추가 비교 지표로 사용합니다. 현재 귀가 안전률이나 CCTV 가동 상태가 아닙니다.
- 5~60분, 분당 1분 단위, 걷기 속도 4km/h 가정. 최장 5개 후보·순환형 우선·왕복형 보완. 서로 겹치는 경로를 제한하는 휴리스틱(대략 72% 기준)을 적용했습니다.
- 실용적 비교를 위해 조명/안심 **근접률 최상 후보**를 표시합니다. 이때 후보가 왕복형이면 순환형 뒤에 배치합니다. 장시간 후보 중 일부는 목표 시간 오차가 있습니다.
- 편의점 위치를 이용한 경로 비교와 `24/7` 조명 효과는 **시연 가정**으로, 실제 점포 영업 여부/빛은 확인되지 않았으며 **경로 점수에도 반영하지 않습니다.**
- 빛 번짐/작은 점멸은 화면 장식입니다. 점등 상태 관측도 아닙니다.

## 데이터 검증 기록 (비좌표 요약)

| 항목 | 검증 기록 |
|---|---|
| NGII 조명 기록 | 9,193건 (가로등 2,650·보안등 6,543); UFID·좌표 중복 검사 0 |
| 수치지도 도엽 범위 | 조명 레이어가 있는 39/41 도엽, 1km 시험구역 도엽 범위 약 97.17% |
| 보행 후보망 | 제공 OSM 시험 캐시의 도심 필터 후 3,847개 구간 |
| OSM 편의점 | 시험 기준 반경 1km 안 26건; 해당 자료에서 영업시간 태그 없음 |
| 안심 인프라 | 2022년 과거 구간 3개·시설 32건; 현행 미검증 |
| 좌표 중복 우려 | 2026 IoT/2022 기록 537개가 NGII와 근접한 경우 다수. 물리적인 독립 등기구 수로 합산 금지 |

**주의:** 도엽의 커버리지 ≠ 조명 설치 전수/실제 조도 확보율. 모델 근접률 ≠ lux/실제 안전성. 광원·도로·시설 자료의 최신성이나 실제 보행 가능성을 현장 확인한 것은 아닙니다.

## 시험 범위

Node 가상 그래프와 사용자 제공 OSM 파일 기반 개발 중 자동 테스트를 거쳤고, 최신 `v0.8.12.9`를 사용자 PC에서 정상 확인했습니다. **현재 공개 ZIP 자체는 OSM/NGII 실데이터를 포함하지 않으므로**, 모든 연구 시나리오를 재현할 수 없습니다. 저장소 자체에는 가상 그래프 기반 검증 코드만 남겼습니다.
