# v0.8.12.7: 코스 선택 시 지도선 유지

## 문제
v0.8.12.6의 `confirmChoice()`가 `routeLayer.clearLayers()`를 호출하여 코스 확정 시 경로가 지도에서 사라졌음. 이는 사용자 제보 스크린샷으로 재현됨.

## 조치
코스 확정 시 `drawRoute(route)`를 호출하여 선택한 코스만 민트색 실선으로 표시. 미리보기 단계의 다른 후보 점선은 제거. 접기·X는 결과창만 숨기고, `선택 취소`는 후보 목록과 지도를 복원하며 `경로 지우기`만 지도 경로를 삭제.

## 비영향 범위
41도엽 NGII 조명 좌표·OSM 보행망·2022 안심 기록, 추천 점수·경로 탐색 알고리즘, 편의점 로직, 기존 야탑동 원본은 변경하지 않음.

## 검증
Node 선택/취소/지우기 상태 전환 구조 테스트, 기존 회귀 테스트. 실제 브라우저 클릭 및 화면 표시 확인은 사용자 PC에서 수행 필요.
