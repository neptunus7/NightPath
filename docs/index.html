분석 안내 · 실제 밝기·보행 안전 보장 아님

시연용으로 생성한 가상 조명 위치를 바탕으로 계산한 조명시설 접근성을 표시합니다. 실제 조도·점등·보행 안전을 보증하지 않습니다. 실제 OSM 보행 후보망이라도 현장 통행 가능 여부는 보장하지 않습니다.

01 밤의 목적

어떤 밤이든, 길을 선택할 수 있도록.

최광루트는 조명시설 근접도를 우선합니다. 안심 인프라 참고형은 가상 안심구간 및 CCTV·안심벨·112 안내 위치을 함께 고려합니다. 어느 모드도 실제 안전을 보장하지 않습니다.

OSM 태그에서 확인되는 비포장·산길·계단·급경사·lit=no 일부 경로를 제한합니다. 태그가 없거나 틀리면 산지 경로가 남을 수 있으며 야간 안전을 보증하지 않습니다.

5분60분
분 · 슬라이더 위 마우스 휠도 지원

빠른 선택은 기존대로 유지하며, 5~60분을 1분 간격으로 조절할 수 있습니다. 예상 시간은 실제 걸음과 다를 수 있습니다. 출발점으로 돌아오는 경로를 우선 찾습니다. 걷는 속도는 4km/h 가정입니다.

실제 OSM에 기록된 편의점 위치를 이용합니다. 파란빛은 전체 24시간 영업을 가정한 시연용 표시이며 실제 영업 여부가 확인된 것은 아닙니다.

⌁ 편의점 영업시간 수동 확인 · 빛 예시 설정

네이버/카카오 지도 등에서 검색해 사실 여부를 확인할 수 있지만, 타 서비스 정보를 저장·가공·공개하려면 해당 조건을 먼저 확인해야 합니다. 자동 수집하지 않으며 모든 입력은 임시 시각화에만 사용합니다.

네이버 지도에서 확인카카오 지도에서 확인

시연 모드에서는 모든 OSM 편의점을 24시간으로 가정합니다. 실제 영업정보는 미확인입니다.

출발 위치는 기존 설정을 사용해요. 지도를 클릭해 원하는 도착지를 찍으면 거리 우선과 조명 근접도 우선 두 경로를 비교합니다.

아직 지정한 도착지가 없습니다.

실제 OSM의 보행 후보망에 연결되는 위치만 탐색합니다. 최대 35% 우회를 허용하는 조명 근접도 모델이며, 실제 밝기·통행 가능·안전성을 보장하지 않습니다. 실제 도착점과 도로망의 마지막 노드 사이에는 차이가 있을 수 있습니다.

안심 인프라 참고 가상 시연

가상 안심구간과 모의 CCTV·안심벨·112 안내시설의 근접도를 비교하는 연구 기능입니다. 현재 작동·운영·접근 가능 여부는 확인되지 않았습니다.

안전 점수나 긴급 신고 서비스가 아닙니다. 위급할 때는 112에 신고하세요.
03 빛의 기준 분석 반경 · 일반 야간/심야⌄

빛이 실제로 닿는 반경이 아니라 조명시설 근접도 평가를 위한 임시 반경입니다. 해당 지역의 디밍 여부·시간·비율은 확인되지 않았습니다.

04 지도 레이어 조명 · 안심 · 야경⌄

레이어는 화면 표시만 바꿉니다. 접힌 상태에서도 추천 점수에는 로드된 OSM·가상 조명 데이터가 사용됩니다.

가상 조명 · 공개 시연

실제 조명 좌표를 수록하지 않은 데모입니다. 가상 조명은 무작위로 배치되므로 실제 조명 분포, 도엽 범위, 거리 밝기를 나타내지 않습니다. 경로 점수도 합성 자료에 근거한 시연 수치입니다.

조명 근접 반경(가정)은 항상 사용·표시됩니다. 구간 평가에 사용하는 거리 가정이며 실제 조도 범위가 아닙니다.
야경 표현

광원별 자동 색상: 보안등은 흰빛 · 가로등은 노란빛 · 편의점은 은은한 푸른빛. 중심점은 종류별로 작은 색상 점을 유지합니다. 색은 지역 관찰을 바탕으로 한 연출이며 실제 색온도 실측이 아닙니다.

빛 번짐 기본 10%, 반경 원 기본 100%. 반경 원의 새 50%가 직전 버전 최대 100% 밝기에 대응합니다. 새 70%는 직전 최대의 약 1.4배입니다. 그라데이션은 유지하며 거리 가정(m)·경로 점수는 불변입니다.

조명 시설 좌표는 아주 작은 점으로 표시합니다. 화면의 빛 강도는 시각 연출만 조정하며 추천 점수·가정 반경과는 무관합니다.

상업시설 빛 · 임시 시각화

실제 운영시간 확인이 아닌 예시입니다. 24시간 가정을 끄면 직접 입력한 점포만 선택 시각에 표시합니다. 빛은 경로 점수에 반영되지 않습니다.

데모 기본값은 모든 편의점 24시간 운영 *가정*입니다. 확인된 운영시간이 아니고 실제 방문 가능 여부를 보증하지 않습니다. 반경은 매장 좌표 중심의 연출값이며 출입구 방향·광량·점등은 미검증, 점수에 반영하지 않습니다.

OSM .osm/XML 또는 JSON 직접 불러오기

시연판은 ODbL 조건으로 공개된 OSM 보행 후보망으로 시작합니다. 필요하면 브라우저에서 직접 OSM 파일을 임시로 불러올 수 있습니다. 반드시 OpenStreetMap 공식 내보내기에서 저장한 .osm XML이나, geometry가 포함된 OSM JSON을 선택할 수 있습니다. OSM 지도 데이터도 실제 통행 여부를 보증하지 않습니다.

OpenStreetMap 지역별 내보내기 · 1km 주변 영역으로 확대해 다운로드해 주세요. 다운로드된 파일이 아닌 지도 타일 이미지는 불러올 수 없습니다.
