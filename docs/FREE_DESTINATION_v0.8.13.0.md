# 자유 도착지 기능: 모델·오류 처리·검증 (v0.8.13.0)

기존 출발 위치를 이용하며 지도 클릭 지점을 보행 후보망의 가장 가까운 노드로 대응시킵니다. 근처 노드가 없거나 경로가 연결되지 않은 경우에는 오류를 표시합니다. 경로 추정은 **OSM 보행 후보망 노드 간 구간**에만 적용하며 클릭 지점에서 노드까지의 보행 연결을 만들어내지 않습니다.

두 비교 경로는 거리 우선과 조명시설 근접도 우선(기준 거리 대비 최대 35% 우회 가정)입니다. 기존 `routing.mjs`의 `brightestWithinDetour` 모델을 사용하며 전역적으로 가장 밝은 실제 경로를 보장하지 않습니다. 두 방식이 같은 경로를 선택한 경우 이를 공개합니다. 밝기·점등 여부·보행 안전·출입 가능성을 실측하거나 보장하지 않습니다.

공개 소스에 있는 `tests/free-destination-v08130.test.mjs` 및 `tests/free-destination-ui-v08130.test.mjs`는 **가상 그래프/모의 UI**로 경계 상황, 35% 우회, 카드 전환·확정·취소를 검증합니다. 로컬에서는 사용자 제공 OSM/NGII 기록으로 경로 계산도 확인했지만 실데이터 위치 정보는 저장소에 포함하지 않습니다. 실제 Windows 브라우저 사용자 검증은 아직 필요합니다.
